### Getting Started

**Step 1:** Enable GitHub Actions workflows (required for auto-grading):

[![](https://img.shields.io/badge/1.%20Enable%20Workflows-%E2%86%92-0969da?style=for-the-badge&logo=github&labelColor=0550ae)](https://github.com/gotildaayalaluna/GitHubCourse/actions)

> Click the button above, then click **"I understand my workflows, go ahead and enable them"**.  
> Next, select **"Step 0"** from the left sidebar, click **"Run workflow"** → **"Run workflow"**.

**Step 2:** Once Step 0 completes, start your exercise:

[![](https://img.shields.io/badge/2.%20Go%20to%20Exercise-%E2%86%92-1f883d?style=for-the-badge&logo=github&labelColor=197935)](https://github.com/gotildaayalaluna/GitHubCourse/issues/2)
